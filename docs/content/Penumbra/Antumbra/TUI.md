Antumbra includes a TUI together with the CLI module.

To enter the TUI, you can run `antumbra --tui` or `antumbra -t`, or double click the `.exe` file if you are on Windows.
The TUI is designed to be intuitive and easy to use, with simple navigation and customisations.

## The pages

### Welcome page

![[antumbra-tui.png]]

The welcome page is the first page you will see when you enter the TUI. It serves as the entry point for the Device Page, and for the Options Page. You can navigate using the arrow keys [↑/↓], and select an option by pressing Enter.

To enter the Device Page, you'll need to select at least a [[Download Agent|DA]] file. You can do so by pressing Enter on the "Select DA" option. A file explorer will open, allowing you to select the file. Allowed extension for DA is `.bin`.
